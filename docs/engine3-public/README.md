# BAEC Engine 3: Re-engagement Preparation

Version 1.0

**Live demo:** https://baec-engine3.streamlit.app

BAEC Engine 3 prepares a grounded re-engagement conversation after a human has verified that new evidence may correspond to a condition the buyer previously said would make evaluation worth revisiting.

## BAEC workflow

**Remember → Monitor → Recognize → Prepare**

- Engine 1 captures and confirms the buyer-articulated condition.
- Engine 2 monitors for evidence that may correspond to that condition and requires human verification.
- Engine 3 prepares the conversation around that human-verified correspondence.

Engine 3 can prepare:

- Internal Why-Now Summary
- Follow-up Email Draft
- Call Opening Draft
- Discovery Questions

Verified correspondence can justify preparation for a human conversation. It does not establish that contact should occur, that the buyer is evaluating, or that the buyer intends to purchase.

**BAEC prepares the conversation. The salesperson decides whether to have it.**

## Research status

Engine 3 Version 1.0 is a research prototype using synthetic data.

The public demo does not make live model calls, authorize outreach, send email, place calls, create opportunities, change account state, or infer buyer intent.

The BAEC framework has not been empirically validated as a sales-performance system.
